Run `npm run db:import:nestle -- --check` for a local preview, or add `--remote` for a live Cloudflare preview. Remove `--check` to apply. Each import backs up the affected category and products in the ignored `backups/` directory before adding records. It verifies image uploads, imports within a database transaction, and records an audit event. Reruns preserve edited names, prices, availability, images, and category settings. Conflicting SKUs/categories abort the import. Other categories, products, and sales records are untouched.

`prisma/nestle-menu-data.json` holds the workbook data. `docs/nestle-image-sources.json` records the original photograph URLs, source pages, match notes, and SHA-256 checksums. Assets in `public/nestle-ice-cream/` are real packaging photographs resized/compressed as WebP, with white margins that keep the full wrapper visible on POS cards. The importer uploads them to R2 and uses authenticated `/api/media/` URLs, so the new menus work with the existing POS and catalog editor immediately. When improving these imported photos, previous checksums allow replacing only the importer's own image versions; custom images remain intact.
